# Satchel fonts

Two families, each self-hosted under the SIL Open Font License 1.1 with its licence beside the files. No page makes a remote font request.

| Family | Use | Files | Licence | Upstream |
| --- | --- | --- | --- | --- |
| Figtree | headings (800–900, tight tracking), the Satchel wordmark (750) and body text, on the run site and in the app | `figtree/` (Latin, Latin Extended; weights 300–900) | `figtree/LICENSE.txt` | https://github.com/erikdkennedy/figtree |
| JetBrains Mono | code cards and the terminal | `jetbrains-mono/` (Latin; weights 100–800) | `jetbrains-mono/LICENSE.txt` | https://github.com/JetBrains/JetBrainsMono |

The variable WOFF2 subsets come from Fontsource's distributions (`@fontsource-variable/figtree` and `@fontsource-variable/jetbrains-mono` 5.3.0). The design desk's approved pages (17 Oct 2026) were composed in Figtree.
